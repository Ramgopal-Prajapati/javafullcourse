Foundations of Programming

▣ Why Programming?

Definition: Programming is the way humans give instructions to computers to solve problems and automate work.
Use case: Build apps, websites, games, AI, automate boring tasks, analyze data, create startups, get high-paying jobs.
Java
// A computer without code is just metal.
// With code, it becomes Instagram, Netflix, ChatGPT, ISRO satellites...
System.out.println("Code is the new superpower 🚀");
Output
Code is the new superpower 🚀

▣ What is Programming?

Definition: Programming = writing a sequence of instructions (algorithm) in a language the computer understands, which is then translated to machine code.
Use case: Used to build every digital product around you — from a calculator to ChatGPT.
Java
// Recipe analogy: ingredients (data) + steps (logic) = dish (output)
int rice=2, water=4;
int cookedRice = rice + water;
System.out.println("Cups served: " + cookedRice);
Output
Cups served: 6

▣ Communication Process of Programming

Definition: Programmer writes high-level code → Compiler converts it to bytecode/machine code → CPU executes it → Output is shown.
Use case: Understand how your Java file actually runs on Windows, Mac or Linux without any change (Write Once, Run Anywhere).
Java
// Java flow:
// .java  --javac-->  .class (bytecode)  --JVM-->  Machine code  -->  Output
public class Hi { public static void main(String[] a){ System.out.println("Hi"); } }
Output
Hi

Use case: Pick the right tool for the job: C for OS kernels, Java for enterprise, Python for AI, JS for web.
Java
/* Examples:
   C       -> Operating systems, embedded
   C++     -> Game engines, browsers
   Java    -> Enterprise, Android, banking
   Python  -> AI/ML, data, scripting
   JS      -> Web frontend / Node backend
   Go/Rust -> Cloud, systems, performance

System.out.println("Right language → right problem");

Right language → right problem

Definition: A variable is a named memory location that stores a value which can change during program execution.
Use case: Store user input, scores, prices, counters — basically anything dynamic.

▣ Best Example — Print Student Report Card (Static + Dynamic)

Definition: Combines variables, arrays, loops, conditions and methods into a real-world program.
Use case: School/college result systems, payslip, invoice printers.
Java
import java.util.Scanner;
public class ReportCard {
  static String grade(double avg){
    if(avg>=90)return "A+";
    if(avg>=75)return "A";
    if(avg>=60)return "B";
    if(avg>=40)return "C";
    return "F";
  }
  public static void main(String[] args){
    // STATIC values
    String name="Aman Kumar"; String cls="10-A"; int roll=23;
    int[] marks={92,85,78,88,70};
    String[] subs={"Math","Science","English","Hindi","Computer"};

    // DYNAMIC input (uncomment to read)
    // Scanner sc=new Scanner(System.in);
    // System.out.print("Name: "); name=sc.nextLine();
    // ... etc.

    int total=0; for(int m:marks) total+=m;
    double avg=total/(double)marks.length;

    System.out.println("====== STUDENT REPORT CARD ======");
    System.out.println("Name : "+name);
    System.out.println("Class: "+cls);
    System.out.println("Roll : "+roll);
    System.out.println("---------------------------------");
    System.out.printf("%-12s %s%n","Subject","Marks");
    for(int i=0;i<subs.length;i++) System.out.printf("%-12s %d%n",subs[i],marks[i]);
    System.out.println("---------------------------------");
    System.out.println("Total: "+total+"/500");
    System.out.printf("Avg  : %.2f%n",avg);
    System.out.println("Grade: "+grade(avg));
  }
}

▣ Structure & Union (Java equivalent)

Definition: C structures group different types under one name. Java has no struct/union — we use classes (and POJOs/records).
Use case: Model real-world entities: Student, Book, Employee.
Java
// "Structure" in Java -> use a class / record
class Student {
  String name; int roll; double cgpa;

public class Demo{
  public static void main(String[] a){
    Student s = new Student("Riya",12,8.7);
    System.out.println(s.name+" "+s.roll+" "+s.cgpa);
  }
}
// "Union" (one memory shared) — Java has no union; closest is `Object` or sealed interfaces.

Riya 12 8.7

▣ STL vs Java Collections Framework

Definition: C++ STL = Standard Template Library (vector, map, set, queue). Java's equivalent is the Collections Framework in java.util.
Use case: Reusable, type-safe, high-performance data structures with built-in algorithms.
Java
import java.util.*;
public class StlVsJcf{
  public static void main(String[] a){
    List<Integer> v = new ArrayList<>(Arrays.asList(3,1,4,1,5,9));
    Collections.sort(v);          // like std::sort
    Set<Integer> s = new HashSet<>(v);  // like std::set
    Map<String,Integer> m = new HashMap<>();
    m.put("a",1); m.put("b",2);
    System.out.println(v); System.out.println(s); System.out.println(m);
  }
}
Output
[1, 1, 3, 4, 5, 9]
[1, 3, 4, 5, 9]
{a=1, b=2}

▣ Header Files (Java equivalent: import / packages)

Definition: C uses #include for headers. Java uses 'import' to bring in classes from packages.
Use case: Modular code, reuse libraries, organize big projects.
Java
// Create your own "header" -> a utility class in a package
// File: utils/MathHelper.java
package utils;
public class MathHelper {
  public static int square(int x){ return x*x; }
  public static int cube(int x){ return x*x*x; }
}

// File: Main.java
import utils.MathHelper;
public class Main {
  public static void main(String[] a){
    System.out.println("square(5) = " + MathHelper.square(5));
    System.out.println("cube(3)   = " + MathHelper.cube(3));
  }
}
Output
square(5) = 25
cube(3)   = 27

    System.out.println("Map  : "+map);
